# SalonPay - 美髮沙龍員工薪資與抽成計算系統

專為美髮設計師與沙龍店家打造的**互動式網頁薪資與業績管理系統**。免安裝任何資料庫或伺服器，直接雙擊 `index.html` 即可使用任何瀏覽器開啟！

---

## 🌟 核心特色功能

### 1. 下拉選單自動帶入價格與抽成
- 開單時點擊「服務項目」下拉選單（如：精緻剪髮、舒壓洗、溫塑燙、全染、結構式護髮、頭皮SPA等）。
- 系統會**自動帶入預設定價與該項目的抽成比例（%）**。
- 若遇特殊促銷或加長髮加價，可直接在欄位修改單價或抽成趴數，系統立即重算。

### 2. 即時試算「這單抽多少錢」
- 右側顯眼黃金卡片即時顯示**本單設計師總抽成金額**、客單總價與店家淨額。
- 同一顧客若施作多個項目（例如：剪髮 + 染髮 + 護髮），點擊「新增一項服務」即可合單結算。
- 支援指派技術助理，並可設定助理協同獎勵提成。

### 3. 歷史帳單與每日流水
- 自動記錄每筆客單流水號、日期、顧客、施作項目明細與實收金額。
- 支援按月份、員工、顧客關鍵字快速篩選與搜尋。
- 支援一鍵匯出「每日流水 Excel 表格」。

### 4. 月薪試算與月報表匯出（管理員專屬）
- **全月業績自動彙整**：自動統計該員工整月服務客數、總業績與技術抽成總額。
- **純粹簡明薪資結構**：
  $$\text{實發月薪} = \text{業績抽成總計} + \text{其他獎金/補貼}$$
  去除傳統底薪、全勤與各類代扣雜項，純粹依據業績抽成與額外獎金結算。
- **一鍵匯出 Excel 月報表**：包含「月薪資結算總表」與「當月客單流水明細」兩頁工作表（Sheet）。員工端亦可匯出個人當月客單成果。
- **列印 / 存為 PDF 薪資條**：管理員專用美髮業薪資結算單格式，支援直接列印或匯出 PDF。

### 5. 自訂項目與員工管理
- 可自行新增、修改或刪除店內的服務項目、定價與預設抽成比率。
- 可新增多位設計師與助理，並支援與已註冊之雲端帳號綁定。
- 支援完整 JSON 備份與雲端同步。

## 🚀 如何開始使用

1. 在檔案總管中，直接對 `index.html` 點擊滑鼠右鍵選擇「使用 Chrome 或 Edge 開啟」（或直接連點兩下）。
2. 在「現場開單」分頁中：
   - 選擇設計師與日期。
   - 下拉選單選擇服務項目（如：造型剪髮），立即查看價格與抽成。
   - 點擊「儲存此單並計入業績」。
3. 切換到「月薪結算與月報表」分頁：
   - 選擇月份與該設計師。
   - 即可看到全月業績統計與實發薪資，並可點擊「匯出 Excel 月報表」或「列印/存為 PDF 薪資條」！
