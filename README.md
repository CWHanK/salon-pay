# SalonFlow

美髮沙龍現場開單、客單紀錄與店務管理系統。免安裝伺服器，直接使用瀏覽器開啟即可運作，支援跨裝置雲端資料即時同步。

## 快速開始

1. 使用任何瀏覽器（Chrome、Edge 等）開啟 `index.html`。
2. 登入或註冊帳號即可開始使用。

## 開發驗證

使用 Node.js 18 以上版本執行 `node --test tests/live-workflow.test.cjs`，不需安裝額外套件。測試涵蓋即時同步保留開單草稿、人員篩選、小計更新與歷史年份，使用模擬資料，不連線正式 Firebase。
